\# AI Resume Updated



AI-powered resume analysis and recruitment assessment MVP.



\## Features



\- Resume PDF upload

\- Resume text extraction

\- Candidate email extraction

\- Candidate phone extraction

\- Education extraction

\- Experience extraction

\- Skill extraction

\- Job description analysis

\- Skill matching

\- Skill gap identification

\- Candidate match score

\- FastAPI web interface



\## Technology



\- Python

\- FastAPI

\- Uvicorn

\- PyMuPDF

\- Pydantic

\- HTML/CSS
